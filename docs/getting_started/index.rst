***************
Getting Started
***************

Install xnn, run the quickstart example, then train your first model. After
that, the :ref:`how-to guides <how-tos>` will guide you on how to use xnn for
specific tasks. Finally, the :ref:`user guide <user-guide>` will offer a more
detailed reference to the xnn functionality.
